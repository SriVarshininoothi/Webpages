# Tech Shop Website

A responsive e-commerce website built using HTML, CSS, and Bootstrap. This project showcases a modern online tech store interface with multiple pages and a user-friendly design.

## Live Demo

https://varshini-boat-site.vercel.app

##  Features

- Responsive Home Page
- User Login Page
- User Registration (Sign Up) Page
- Product Details Page
- Shopping Cart Page
- Cart Items Management UI
- Responsive Navigation Bar
- Mobile-Friendly Design

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- Vercel (Deployment)
